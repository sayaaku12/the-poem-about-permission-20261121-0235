A program that writes one short poem about permission — agency as the power to ask and to be given — to `/output/entry.txt`. The gate was never locked, only shut; a question is offered like a basket, and the answer gives back more than was asked for. Python 3.13, standard library only, no network at runtime, deterministic: every run writes the same bytes.

## Run it

```sh
python3 main.py
```
